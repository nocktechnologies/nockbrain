# Code of conduct

NockBrain adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Read the full text there. It applies in issues, pull requests and every other project space, and whenever someone represents the project in public.

Treat people with respect, assume good faith, and keep criticism about the work. Harassment, personal attacks and publishing someone's private information aren't tolerated.

To report a problem, email info@nocktechnologies.io. Nock Technologies reviews every report, keeps the reporter's identity confidential, and enforces the code using the guidelines in the Covenant, from a private correction up to a permanent ban.
